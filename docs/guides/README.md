# Guides

Task-oriented walkthroughs for using cadence. New here? Start with **Install &
Quickstart**, then jump to **Videos** for the workflow.

### Getting started
- [Installation & Quickstart](install.md) — from zero to a rendered video, via the skill or the CLI.
- [Per-Project Setup (.cadence/)](project-setup.md) — capture a repo's brand, backgrounds, and output dir so cadence just works against it.

### Make a video
- [Videos](videos.md) — the kind × template model, the `new → edit → storyboard → create` workflow, the five kinds, the honesty ladder, and the panel picker.
- [Composition](composition.md) — the component tree: placement/regions, layout containers (`row`/`col`/`grid`/`group`), per-node style, and sequencing.

### Make it yours
- [Branding, Themes & Formats](branding-and-formats.md) — your colors (auto-discovered `.cadence/theme.json`), code styling, painted backdrops (`cadence art`), and every aspect ratio.
- [Iterate & Preview](iterate-and-preview.md) — storyboard a mock (plan + one still per beat), re-skin, and iterate before you render.

### Automate
- [Ship on Release (CI)](ship-on-release.md) — publish a GitHub release, get a video automatically.
